⚙️ How It Works

End-to-end automated pipeline from live webcam capture to smart recycling guidance.

1
📷

Start Camera

Browser requests webcam access via HTML5 MediaDevices API and streams live video locally without freezing the UI.

2
🧠

AI Analyzes Waste

Frames are resized to 224×224px and processed by FastAPI using our CPU-optimized MobileNetV2 & OpenCV vision pipeline.

3
🏷️

Waste Is Classified

The model predicts probabilities across 6 categories (Plastic, Paper, Metal, Glass, Organic, General Waste).

4
♻️

The smart rule engine maps the item to its colour-coded bin, displays disposal instructions, and logs to SQLite.

Real-Time Detection

Continuous throttled frame capture processes live video smoothly on any standard student laptop without needing a dedicated GPU.

🗑️

Smart Bin Recommendation

Deep Learning + OpenCV

💾

Local SQLite Storage

Zero-configuration local relational database with automatic schema initialization and intelligent duplicate frame debouncing.

🎓 Workshop Guide: About the AI & Architecture

Clear explanations of the core technologies powering this project for student demonstrations.

🤖 What is Deep Learning?

Deep Learning is a subset of Machine Learning based on artificial neural networks with multiple layers. In computer vision, Convolutional Neural Networks (CNNs) like MobileNetV2 automatically learn visual hierarchy—from simple edges and textures in early layers to complex shapes like bottles, cans, and fruit in deeper layers.

🖼️ What is Image Classification?

Image Classification is the computer vision task of taking an input image (a grid of RGB pixels, resized here to 224×224) and outputting a probability distribution over predefined categories. The category with the highest probability score becomes the predicted waste type.

⚡ What is FastAPI?

FastAPI is a modern, high-performance Python web framework for building APIs. It uses Python type hints and Pydantic to automatically validate data, serialize JSON responses, and generate interactive OpenAPI documentation at /docs.

🔄 How Does Real-Time Detection Work?

Instead of sending 60 frames per second (which would overload a laptop CPU), the browser captures a lightweight JPEG snapshot every ~1.2 seconds via an HTML5 <canvas>, sends it to POST /api/predict, displays the result immediately, and applies a 5-second debounce filter before writing to SQLite.
